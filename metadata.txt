Strava API synchronization requires a Strava account and API credentials; bulk-file import does not require API access. Optional Mapbox backgrounds require a Mapbox access token. Static route heatmaps require NumPy in the QGIS Python environment. FIT/PDF dependencies (fitdecode and pypdf) are bundled. See the homepage for setup and usage.
